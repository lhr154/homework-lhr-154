# 实验5：多档位触摸调速呼吸灯

## 实验目的
结合呼吸灯和触摸开关，实现触摸切换呼吸速度的功能。

## 硬件连接
| 元件 | 引脚 |
|------|------|
| LED | GPIO 2 |
| 触摸引脚 | GPIO 4 |

## 代码文件
- **code_breath-touch_05**：多档位触摸调速呼吸灯

## 代码说明
- 呼吸灯部分：使用 `ledcAttach` 和 `ledcWrite` 实现 PWM 呼吸效果
- 触摸部分：边缘检测 + 防抖，每次触摸切换档位
- 档位变量 `speedLevel`：1档（慢速）、2档（中速）、3档（快速）
- 非阻塞呼吸：使用 `millis()` 代替 `delay()`，确保触摸实时响应

## 实验现象
- 上电后 LED 慢速呼吸（1档）
- 触摸一次：呼吸变快（2档）
- 再触摸一次：呼吸更快（3档）
- 再触摸一次：回到慢速（1档）
