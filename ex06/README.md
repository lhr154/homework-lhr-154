# 实验6：警车双闪灯效

## 实验目的
使用双通道 PWM 实现红绿 LED 交替闪烁的警车灯效果。

## 硬件连接
| 元件 | 引脚 |
|------|------|
| 红色 LED | GPIO 2 |
| 绿色 LED | GPIO 5 |
| 220Ω电阻 ×2 | 串联在两个 LED 正极 |

## 代码文件
- **code_Alternating-breathing_06**：红绿交替渐变

## 代码说明
- 使用 `ledcAttach` 绑定两个 PWM 引脚
- 亮度渐变：0→255→0 循环
- 红绿交替：红色亮时绿色灭，红色灭时绿色亮
- 使用 `millis()` 非阻塞控制渐变速度

## 实验现象
- 红色 LED 逐渐变亮，同时绿色 LED 逐渐变暗
- 红色达到最亮时，绿色完全熄灭
- 然后红色逐渐变暗，绿色逐渐变亮
- 循环往复，形成红绿交替闪烁的警车灯效果
