# 实验4：触摸引脚控制LED

## 实验目的
学习使用 ESP32 的触摸引脚控制 LED。

## 硬件连接
| 元件 | 引脚 |
|------|------|
| LED | GPIO 2 |
| 触摸引脚 | GPIO 4 |

## 代码文件

### 1. code_touch_04（基础触摸）
- **功能**：触摸时 LED 亮，松开时 LED 灭
- **特点**：无防抖，无边缘检测，直接根据触摸值控制 LED

### 2. code_new-touch_04（触摸自锁开关）
- **功能**：摸一下 LED 亮并保持，再摸一下 LED 灭
- **特点**：
  - 布尔变量 `ledState` 记录 LED 状态
  - 边缘检测：判断“从未触摸到触摸”的瞬间
  - 软件防抖：50ms 内只响应一次，防止误触发

## 实验现象

### code_touch_04
- 手指触摸引脚 → LED 亮
- 手指松开 → LED 灭

### code_new-touch_04
- 初始状态：LED 灭
- 第一次触摸：LED 亮并保持
- 第二次触摸：LED 灭并保持
- 重复循环
